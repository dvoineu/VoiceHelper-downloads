## English

VoiceHelper 1.1 (build 3) — voice dictation at your text cursor for macOS.

**Requirements:** macOS 13 Ventura or later and a Mac with Apple Silicon (M1 or later), arm64. An Intel build is not included. The same installer includes English and Russian interface languages; separate language downloads are not needed.

### Download and install

1. Download `VoiceHelper-1.1-3-arm64.dmg` or `VoiceHelper-1.1-3-arm64.zip` from Assets below. GitHub's automatic “Source code” archives contain website files, not the application.
2. Open the DMG or extract the ZIP, move VoiceHelper.app to Applications and launch it.
3. Allow Microphone and Accessibility, then download a local recognition model in Settings.
4. Focus a text field and press Option-Space to start and stop dictation.

Local recognition is free and works offline after the model download. Cloud services are optional, use your own API key and may charge separately. There is no automatic updater: quit the app and replace it in Applications to install another version.

### Website language

The [website](https://dvoineu.github.io/VoiceHelper-downloads/) opens in English on the first visit. Choose **English / Русский** in the header to change language; your choice is remembered when browser storage is available. You can also open [English directly](https://dvoineu.github.io/VoiceHelper-downloads/?lang=en) or [Русский directly](https://dvoineu.github.io/VoiceHelper-downloads/?lang=ru).

### Verify the downloads

The app is Developer ID signed and Apple notarized. DMG integrity, the signature, stapled notarization ticket and Gatekeeper assessment of the app extracted from the final ZIP were checked. Both published installers were downloaded anonymously and their SHA-256 values matched the original verified files.


`INSTALL.txt` includes English and Russian installation instructions. Place the installers beside `SHA256SUMS` and run `shasum -a 256 -c SHA256SUMS` to verify them.

**Verification limits:** installation on a clean second Mac, offline launch and upgrade testing with permissions and login items remain unverified. Signing and notarization do not establish that these installation tests have passed.

## Русский

VoiceHelper 1.1 (сборка 3) — голосовой ввод у текстового курсора для macOS.

**Требования:** macOS 13 Ventura и новее, Mac с Apple Silicon (M1 и новее), arm64. Сборка для Intel не включена. Один и тот же установщик содержит английский и русский языки интерфейса; отдельные языковые архивы не нужны.

### Скачать и установить

1. Скачайте `VoiceHelper-1.1-3-arm64.dmg` или `VoiceHelper-1.1-3-arm64.zip` из раздела Assets ниже. Автоматические архивы GitHub «Source code» содержат файлы сайта, а не приложение.
2. Откройте DMG или распакуйте ZIP, перенесите VoiceHelper.app в «Программы» и запустите.
3. Разрешите микрофон и «Универсальный доступ», затем скачайте локальную модель распознавания в настройках.
4. Установите курсор в текстовое поле и нажимайте Option-Пробел для запуска и остановки диктовки.

Локальное распознавание бесплатно и работает без интернета после загрузки модели. Облачные сервисы необязательны, используют ваш API-ключ и могут взимать плату. Автоматического обновления нет: для установки другой версии закройте приложение и замените его в «Программах».

### Язык сайта

[Сайт](https://dvoineu.github.io/VoiceHelper-downloads/) при первом визите открывается на английском. Выберите **English / Русский** в шапке для смены языка; выбор сохраняется, если браузер разрешает локальное хранение. Также доступны прямые ссылки на [русскую](https://dvoineu.github.io/VoiceHelper-downloads/?lang=ru) и [английскую](https://dvoineu.github.io/VoiceHelper-downloads/?lang=en) версии.

**Ограничения проверки:** установка на чистый второй Mac, запуск без сети и обновление с проверкой разрешений и автозапуска пока не подтверждены. Подпись и нотарификация сами по себе не означают, что эти проверки установки выполнены.
