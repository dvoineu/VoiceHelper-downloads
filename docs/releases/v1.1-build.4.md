## English

VoiceHelper 1.1 (build 4) — guided setup for your first dictation.

### What’s new

- A new setup window walks through Microphone access, Accessibility, recognition and a trial dictation.
- Close setup and resume at the same step. You can also skip it and return using **Set Up VoiceHelper…** in the menu or **General → Set Up VoiceHelper Again…**.
- Check your shortcut and dictate into the trial field. Setup finishes after the phrase is confirmed there; the trial does not send Return.
- See model sizes and free disk space before downloading. A trial can wait for the selected model to finish downloading.
- API key checks follow the current key and server, avoiding outdated confirmation after either changes.
- Updating preserves settings, API keys, downloaded models and storage preferences. Setup appears for users who have not completed or skipped it.

### Download and install

**Requirements:** macOS 13 Ventura or later, Apple Silicon (M1 or later), arm64. No Intel installer is included. One installer contains both English and Russian interfaces.

1. Download `VoiceHelper-1.1-4-arm64.dmg` or `VoiceHelper-1.1-4-arm64.zip` from Assets. GitHub’s automatic “Source code” archives contain website files, not the app.
2. Quit an older VoiceHelper, move the new VoiceHelper.app to Applications and launch it.
3. Follow setup to allow Microphone and Accessibility, then download a local recognition model or check your optional cloud API key.
4. Try a phrase in the setup field with your displayed shortcut, then use it in other apps.

Local recognition is free and works offline after the model download. Optional cloud services use your own API key and may charge separately. There is no automatic updater; replace the app in Applications to update. You can restore the previous [build 3](https://github.com/dvoineu/VoiceHelper-downloads/releases/tag/v1.1-build.3) after quitting the app.

### Verification and limits

The app is Developer ID signed and Apple notarized. The release process checks strict signatures, stapled tickets, Gatekeeper, the app extracted from the final ZIP and the app mounted from the final DMG. `SHA256SUMS` lists both installer hashes; `INSTALL.txt` contains English and Russian instructions.

Place the installers beside `SHA256SUMS` and run:

```sh
shasum -a 256 -c SHA256SUMS
```

The owner manually accepted the onboarding build; 305 Swift tests completed with 0 failures and 5 optional hardware/corpus tests skipped. Packaging and release fixtures are checked separately. Clean second-Mac installation, macOS 13 runtime, offline launch, upgrade with permission/login-item checks, light-mode/VoiceOver and the full hardware/provider matrix remain unverified; signing does not establish those results.

## Русский

VoiceHelper 1.1 (сборка 4) — пошаговая настройка до первой диктовки.

### Что нового

- Новый мастер проводит через доступ к микрофону, универсальный доступ, выбор распознавания и пробную диктовку.
- Закройте мастер и продолжите с того же шага. Можно пропустить настройку и вернуться через **«Настроить VoiceHelper…»** в меню или **«Основное → Настроить VoiceHelper заново…»**.
- Проверьте сочетание клавиш и продиктуйте фразу в поле мастера. Настройка завершается после подтверждённой вставки; после пробы клавиша Return не нажимается.
- До загрузки видны размер модели и свободное место на диске. Пробная диктовка может дождаться окончания загрузки выбранной модели.
- Проверка API-ключа учитывает текущий ключ и сервер: устаревший ответ не подтверждает изменённые параметры.
- Обновление сохраняет настройки, API-ключи, скачанные модели и режим хранения. Мастер появится у тех, кто ещё не завершил и не пропустил настройку.

### Скачать и установить

**Требования:** macOS 13 Ventura и новее, Apple Silicon (M1 и новее), arm64. Установщика для Intel нет. Один установщик содержит русский и английский интерфейс.

1. Скачайте `VoiceHelper-1.1-4-arm64.dmg` или `VoiceHelper-1.1-4-arm64.zip` из Assets. Автоматические архивы GitHub «Source code» содержат файлы сайта, а не приложение.
2. Закройте прежнюю версию, перенесите новый VoiceHelper.app в «Программы» и запустите.
3. В мастере разрешите микрофон и универсальный доступ, затем скачайте локальную модель или проверьте ключ необязательного облачного сервиса.
4. Продиктуйте фразу в поле мастера показанными клавишами, затем используйте их в других приложениях.

Локальное распознавание бесплатно и работает без интернета после загрузки модели. Облачные сервисы необязательны, используют ваш API-ключ и могут взимать плату. Автоматического обновления нет: замените приложение в «Программах». Для отката закройте его и восстановите предыдущую [сборку 3](https://github.com/dvoineu/VoiceHelper-downloads/releases/tag/v1.1-build.3).
