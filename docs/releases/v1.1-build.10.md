# Frazia 1.1 (10) · macOS · Apple Silicon

[English](#english) · [Русский](#русский)

## English

- Usage analytics is now enabled automatically in the production app, without a consent prompt or toggle. Previously saved analytics refusals no longer prevent collection after updating. Frazia sends limited setup, dictation-outcome and error statistics to PostHog; audio and dictation text are not included.
- Existing installation identities and first-observed markers are preserved across updates. Website/app linking remains an explicit action in Settings → General.

For macOS 13 or later on Apple Silicon. Quit Frazia, replace Frazia.app in Applications with this build, and launch it again. Homebrew users can run `brew update && brew upgrade --cask frazia`. Automatic application updates are not available. Settings, keys and downloaded models keep their existing locations.

## Русский

- Аналитика использования теперь включается автоматически в production-приложении, без запроса согласия и переключателя. Ранее сохранённый отказ от аналитики после обновления больше не блокирует сбор. Frazia отправляет в PostHog ограниченную статистику настройки, результатов диктовки и ошибок; аудио и текст диктовок не передаются.
- При обновлении сохраняются идентификатор установки и отметка первого наблюдаемого запуска. Связывание с посещением сайта остаётся отдельным действием в разделе «Настройки → Основное».

Для macOS 13 и новее на Apple Silicon. Завершите Frazia, замените Frazia.app в папке «Программы» этой сборкой и запустите снова. Для Homebrew: `brew update && brew upgrade --cask frazia`. Автоматическое обновление приложения пока не поддерживается. Настройки, ключи и скачанные модели используют прежние расположения.

## Verification and limitations / Проверки и ограничения

The app and DMG were signed with Developer ID, accepted by Apple notarization and stapled. The final DMG and the app extracted from both DMG and ZIP passed signature, stapler and Gatekeeper checks. Automated checks completed: 356 Swift tests (5 skipped, 0 failures), 35 Python packaging/release/site tests and the JavaScript analytics, linking and release-resolution suites. Native arm64 build, minimum declared macOS 13. A clean second-Mac installation and the full hardware/macOS matrix remain unverified.

Приложение и DMG подписаны Developer ID, приняты сервисом notarization Apple и снабжены ticket. Финальный DMG и приложение из DMG и ZIP прошли проверки подписи, stapler и Gatekeeper. Выполнены 356 Swift-тестов (5 пропущены, ошибок нет), 35 Python-тестов упаковки/релиза/сайта и JavaScript-тесты аналитики, связывания и выбора релиза. Сборка arm64, заявленный минимум — macOS 13. Установка на отдельном чистом Mac и полная матрица оборудования/macOS остаются непроверенными.
