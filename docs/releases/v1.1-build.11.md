# Frazia 1.1 (11) · macOS · Apple Silicon

[English](#english) · [Русский](#русский)

## English

- Added built-in verified updates powered by Sparkle 2: use **Check for Updates…** in the menu bar or configure **Settings → General → Updates** (`Stable` or `Beta` channel, optional daily automatic checks, `SUSendProfileInfo = false`).
- Background checks show a gentle menu bar indicator without stealing focus, and update relaunch waits until active dictation finishes.
- Updates are delivered as notarized ZIP archives signed with Ed25519 (`SUPublicEDKey`) and re-verified against Frazia’s Developer ID Designated Requirement before replacing `Frazia.app` in place, preserving Accessibility, settings, Keychain keys, and downloaded Whisper models.

For macOS 13 or later on Apple Silicon. From `1.1 (11)` onward, Frazia can update itself directly from **Check for Updates…**; users updating from `1.1 (10)` or earlier need one manual replacement in Applications (drag `Frazia.app` and choose **Replace**) or `brew update && brew upgrade --cask frazia`.

## Русский

- Добавлены встроенные проверяемые обновления на базе Sparkle 2: выберите **«Проверить обновления…»** в строке меню или настройте раздел **Настройки → Основное → Обновления** (канал `Стабильный` или `Бета`, ежедневная автопроверка по желанию, отправка данных о системе отключена).
- Фоновая проверка отображает мягкий индикатор в строке меню без перехвата фокуса, а перезапуск откладывается до завершения активной диктовки.
- Обновления доставляются в нотаризованном ZIP-архиве с подписью Ed25519 и дополнительно проверяются по Developer ID Designated Requirement до замены `Frazia.app` на месте — «Универсальный доступ», настройки, ключи и скачанные модели Whisper сохраняются.

Для macOS 13 и новее на Apple Silicon. Начиная с версии `1.1 (11)`, Frazia обновляется автоматически через **«Проверить обновления…»**; пользователям версии `1.1 (10)` и старше нужно один раз заменить `Frazia.app` в «Программах» вручную (выбрав **«Заменить»**) или выполнить `brew update && brew upgrade --cask frazia`.

## Verification and limitations / Проверки и ограничения

The app and DMG were signed with Developer ID, accepted by Apple notarization and stapled. The final DMG and the app extracted from both DMG and ZIP passed signature, stapler and Gatekeeper checks, and the ZIP enclosure passed Sparkle `sign_update --verify`. Automated checks completed: 363 Swift tests (5 skipped, 0 failures), 39 Python packaging/release/site tests and the JavaScript analytics, linking and release-resolution suites. Native arm64 build, minimum declared macOS 13. A clean second-Mac installation/update and the full hardware/macOS matrix remain unverified.

Приложение и DMG подписаны Developer ID, приняты сервисом notarization Apple и снабжены ticket. Финальный DMG и приложение из DMG и ZIP прошли проверки подписи, stapler и Gatekeeper, а ZIP-пакет прошёл проверку `sign_update --verify` для Sparkle. Выполнены 363 Swift-теста (5 пропущены, ошибок нет), 39 Python-тестов упаковки/релиза/сайта и JavaScript-тесты аналитики, связывания и выбора релиза. Сборка arm64, заявленный минимум — macOS 13. Установка и обновление на отдельном чистом Mac и полная матрица оборудования/macOS остаются непроверенными.
