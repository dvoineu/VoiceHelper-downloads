# Frazia downloads

[Official website](https://dvoineu.github.io/Frazia/) · [Downloads and release notes](https://github.com/dvoineu/VoiceHelper-downloads/releases)

This repository retains the published application installers and release notes.
The former GitHub Pages homepage forwards visitors to the Frazia website,
preserving the query string (including language) and section fragment.

Website source and future page changes belong in [dvoineu/Frazia](https://github.com/dvoineu/Frazia).
Existing media paths are retained for older shared links.
The original release files are preserved under their versioned URLs.

Run `python3 Tests/site_test.py` before changing the forwarding page.
Changes go through an Issue branch and PR targeting main.
